Installing
The .zip and the .tar.gz hold the same thing: one directory tclpdfPACKAGE_VERSION with the Tcl modules, pkgIndex.tcl and the ICC profiles - nothing to build. Extract it into a directory on the auto_path of your tclsh and package require tclpdf finds it. The source archive carries the tests, the examples with their fonts, the manual sources and the tools, and installs the TEA way: ./configure; make test; make install.
 
Requirements
Tcl 8.6.11 or newer, including Tcl 9. Nothing else is required: zlib is a built-in command, not a package, and Tk is not used.
 
Optional Package
One, and it is not shipped with tclpdf.
tdom 0.9.0 or newer needed for the XMP metadata packet, so every document that declares PDF/A, PDF/UA or ZUGFeRD needs it; a document that makes no such claim runs without it. The SVG module uses it as well when present: it parses 27 to 48 times faster than the parser tclpdf brings along and refuses an entity expansion bomb - without it SVG still works, through the built-in element tree parser.
